Project 03 — Penn Electric Racing
Aero Subsystem · First in Team History

Drag Reduction System (DRS)

Worked with two other rookies to develop the team's first-ever DRS — an 800 psi pneumatic system achieving 40% drag reduction.

CFD & Competition-Point Validation

  • Ran parallel competition simulation & CFD development to set target mass and drag reductions against a 5 competition-point goal.
  • Constraints: 2 kg max mass for 5 points and a target C_d = 1.0.
  • Used a 2D genetic algorithm to find the optimal minimal-drag configuration; delta-velocity CFD confirmed gains on the Endurance track.

800 psi Pneumatic Actuation

  • Designed an 800 psi pneumatic loop with two adjustable step-down regulators (80 psi operating), an 800 psi purge valve, and a 3000 psi burst disk for safe operation.
  • Built an MDF prototype to iterate the actuation linkage before committing to final hardware.
  • Achieved a 40% drag reduction on straights.
